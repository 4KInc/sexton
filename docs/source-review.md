# Source review

Proposed sources for the cause lines in the case notes (tasks 25 and 26, requirement R14). Nothing here is in `docs/methodology.md` yet. The owner opens each URL and marks each row **approved** or **rejected** in the Decision column. Only approved rows go into the Sources table of `docs/methodology.md`, and the orbital-coroner agent writes case notes from those rows only.

## Process

1. For each satellite, search the web and open the pages. Propose at most two sources, ranked: operator or agency statement, then FCC, ITU or regulator filing, then a reputable trade or news outlet, then anything else. Wikipedia is never the source.
2. The cause is one of: "failed in orbit or broke up before disposal", "disposal reported by operator", "disposal attempted, perigee short", "no disposal reported", "No cause in the sources opened". ("Disposal reported by operator" was added on 2026-11-27 at the owner's request, for a source that reports a completed disposal.)
3. The quote is the words on the opened page. It is not a paraphrase. A translation, where the page is not in English, is marked as mine and is not the quote.
4. If no opened page supports a cause, the row says "No cause in the sources opened".
5. The owner opens the URLs and fills in the Decision column. Nothing is written into the case notes before that.

### USA 340 (55138) check, so far

Done from the committed files, before any case note. Task 25 records it in the case file and the journal.

- SATCAT (`data/raw/2026-11-22/satcat.csv`): type PAY, status code "-", owner US, launched 2022-11-01, apogee 36420 km, perigee 35351 km, inclination 5.94°, period 1441.15 min.
- The 2026-11-22 GPZ files do not contain 55138, as expected: its apogee (+634 km) is outside the ±200 km zone. The GPZ status table has no row for it either, so its status comes from SATCAT alone.
- `data/raw/2026-11-20/gpz-plus.csv` (kept only as evidence, not a source) has mean elements: mean motion 0.99920006 rev/day, eccentricity 0.01264808, inclination 5.9359°. Those give the same perigee and apogee as SATCAT to within a few km (my own arithmetic, WGS-72, to be redone in the task).
- So SATCAT and the GP-PLUS elements agree. The engine says unquiet because the apogee is above the zone's lower edge. Fallen needs the whole orbit below the zone. The verdict follows from the engine's rules.
